## Known limitations (rigor follow-ups, not blockers)

- **No propagation-specific placebo yet.** The gate's placebo is self-edge
  (random company-days). A propagation null (shuffle target assignments) would
  strengthen edge results. Design note in `docs/specs/2026-07-22-autopilot-design.md`.
- **Resolver is conservative on recall.** It refuses distinctive single tokens
  like "Deckers"→DECK to avoid "Puma"→PBYI. A curated alias map would recover
  those. Precision-over-recall is deliberate.
